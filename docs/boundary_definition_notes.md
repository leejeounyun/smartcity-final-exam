# 경계 정의 메모

## 1. 분석 대상 경계 정의

본 과제에서 비교 대상은 `판교 제1테크노밸리`와 `청라 국제업무지구`이다. 다만 실제 공공데이터 분석에서는 고시 경계와 개별 데이터의 공간 단위가 완전히 일치하지 않기 때문에, 본 연구는 **공식 계획도와 현장 공간구조를 함께 고려한 분석용 경계**를 사용한다.

### 판교

판교는 `판교역을 중심으로 형성된 제1테크노밸리 핵심 업무 블록`을 중심으로 경계를 설정하였다. 경계는 도로와 블록 단위를 따라 직접 디지타이징했으며, 북측 및 동측의 대규모 업무·연구개발 시설 집적지와 판교역 인접 업무 블록을 포함한다.

보고서에는 아래 문장을 기준으로 사용한다.

> 본 연구의 판교 경계는 제1테크노밸리의 법정 경계를 기계적으로 복제한 것이 아니라, 판교역 중심의 실질적 업무지구를 비교하기 위해 공식 계획도와 도로·블록 경계를 함께 고려하여 설정한 분석용 경계이다.

### 청라

청라는 `청라 국제업무지구로 계획된 핵심 블록군`을 기준으로 경계를 설정하였다. 경계는 공식 계획도에 제시된 국제업무지구 범위를 따르되, 실제 데이터 처리와 면적 산정을 위해 도로·블록 경계를 따라 직접 디지타이징하였다.

보고서에는 아래 문장을 기준으로 사용한다.

> 청라 경계는 국제업무지구 계획 범위를 기준으로 하되, 실제 토지이용·건축물·집계구 데이터를 안정적으로 결합할 수 있도록 도로 및 블록 경계에 맞춰 분석용 경계로 재구성하였다.

## 2. 경계 설정 원칙

두 지역 모두 다음 원칙을 동일하게 적용한다.

1. 경계는 배경지도 상에서 식별 가능한 `도로`, `블록`, `대형 필지 경계`를 우선 기준으로 한다.
2. 떨어진 블록이더라도 동일한 업무지구의 구조적 일부라면 하나의 분석 대상에 포함한다.
3. 경계는 GIS에서 직접 디지타이징한 분석용 경계이며, 보고서에 이 사실을 명시한다.
4. 이후 토지이용, 건축물, 집계구 데이터는 모두 이 동일한 경계를 기준으로 클립 및 집계한다.

## 3. 해석상 주의

- 본 경계는 `행정구역 경계`가 아니다.
- 본 경계는 `분석 목적상 정의된 업무지구 경계`다.
- 따라서 결과 해석은 "해당 업무지구 중심부의 구조적 특성 비교"라는 관점에서 제시한다.

## 4. 보고서용 짧은 표현

보고서 본문에는 아래처럼 짧게 정리해도 된다.

> 두 지역의 경계는 공식 계획자료를 참고하되, 실제 공간데이터 결합의 일관성을 확보하기 위해 도로 및 블록 경계를 따라 직접 디지타이징한 분석용 경계를 사용하였다.
